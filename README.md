# Atlas OS

Private Personal Intelligence Operating System.

Atlas is the executive intelligence layer between the owner and everything else:

**Owner → Atlas → capabilities / future Operatives → results.**

This repository is in the architecture phase. There is no application runtime yet.

## Phase 1 intent

A narrow, real vertical slice:

- authenticated private shell
- streaming Atlas intelligence
- persistent structured memory
- project / business context
- command home that only uses real data

No fake operatives, metrics, memories, or integrations.
